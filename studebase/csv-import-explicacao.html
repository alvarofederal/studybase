📥 Importação em Lote via CSV

Como funciona o upload de questões no StudyBase — guia completo

📁
1 — Você prepara o arquivo CSV
Um arquivo de texto com colunas separadas por vírgula. Pode ser criado no Excel, Google Sheets ou qualquer editor de texto.

Colunas obrigatórias: pergunta, opcaoA, opcaoB, opcaoC, opcaoD, correta
Colunas opcionais: explicacao, dificuldade, tags
🖥️
2 — Você abre o tópico no admin e clica em "⬆ CSV"
Dentro de /admin/materias/[slug], seleciona um bloco e um tópico. Na seção de questões, o botão ⬆ CSV abre um modal com um campo de texto onde você cola o conteúdo do arquivo.
👁️
3 — O sistema faz uma pré-visualização
Ao colar o CSV, o código em JavaScript faz o parse localmente (no seu navegador) e exibe uma tabela de prévia com todas as questões detectadas, marcando em vermelho as linhas com erro antes de enviar qualquer coisa.
☑️
4 — Você escolhe o modo: Adicionar ou Substituir
Há um checkbox "Substituir todas as questões existentes".
• Desmarcado (padrão): as questões novas são adicionadas às existentes.
• Marcado: todas as questões do tópico são apagadas antes de inserir as novas — ideal para re-importar uma versão atualizada do CSV sem duplicar.
🚀
5 — Clica em "Importar" e o banco é atualizado
O front-end envia um POST /api/admin/quiz/import com as questões já parseadas. A API cria cada questão com suas 4 opções no banco (MySQL/MariaDB via Prisma) e retorna o resultado: quantas foram criadas, quantas foram apagadas, e se houve algum erro por linha.

📋 Colunas do CSV e seus valores

Coluna Obrigatória? Valores aceitos Descrição
pergunta ✅ Sim Qualquer texto Enunciado completo da questão
opcaoA ✅ Sim Qualquer texto Texto da alternativa A
opcaoB ✅ Sim Qualquer texto Texto da alternativa B
opcaoC ✅ Sim Qualquer texto Texto da alternativa C
opcaoD ✅ Sim Qualquer texto Texto da alternativa D
correta ✅ Sim A, B, C ou D Letra da alternativa correta (maiúscula ou minúscula)
explicacao ⬜ Opcional Qualquer texto Justificativa exibida ao aluno após responder
dificuldade ⬜ Opcional FACIL, MEDIO ou DIFICIL Nível da questão. Se omitido ou inválido, assume MEDIO
tags ⬜ Opcional tag1,tag2,tag3 Tags separadas por vírgula para filtro futuro

➕ Modo: Adicionar (padrão)

Checkbox desmarcado.

As questões do CSV são adicionadas às que já existem no tópico. Útil para complementar um tópico com questões extras sem apagar nada.

🔄 Modo: Substituir tudo

Checkbox marcado — botão fica âmbar como aviso.

O sistema apaga todas as questões existentes do tópico e insere as do CSV do zero. Ideal para re-importar uma versão revisada do arquivo sem criar duplicatas.

⚠️
Atenção ao usar "Substituir tudo": a exclusão é em cascata — apaga as questões e todas as respostas dos alunos vinculadas a elas. Use no modo de preparação do conteúdo, antes de liberar o tópico para os alunos.

✏️ Exemplo real de CSV

pergunta,opcaoA,opcaoB,opcaoC,opcaoD,correta,explicacao,dificuldade,tags

📡 O que a API retorna após a importação

{
  "criadas": 83,   // questões inseridas com sucesso
  "apagadas": 42,  // questões removidas (modo substituir)
  "erros": []      // linhas que falharam (ex: "correta" inválida)
}

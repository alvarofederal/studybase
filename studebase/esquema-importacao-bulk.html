④ Modos de importação

➕

Adicionar (padrão)

Insere as novas questões e flashcards sem apagar o que já existe no banco. Ideal para complementar um tópico com mais conteúdo ao longo do tempo.

Nenhum dado é apagado
Não exige dupla confirmação
Botão verde
🔄

Substituir tudo (destrutivo)

Apaga todas as questões e flashcards da matéria inteira antes de inserir os novos dados. Use para reimportar uma versão revisada sem criar duplicatas.

Exige backup baixado (passo 1)
Exige 2º checkbox de confirmação
Botão vermelho como aviso visual

⑤ Arquitetura das APIs

PAGE
/admin/materias/[slug]/importar
Página client-side com os 4 passos. Parse do CSV feito localmente no browser antes de qualquer requisição ao servidor.
GET → /export → backup.json
🗄️
MariaDB
via Prisma
POST → /import-bulk → JSON result
GET
/api/admin/materias/[slug]/export
Lê matéria completa (blocos→tópicos→quizzes→flashcards) e retorna JSON com header de download. Auth: admin obrigatório.
POST
/api/admin/materias/[slug]/import-bulk
Recebe { questoes[], flashcards[], substituir }. Match por nome de bloco/tópico. Se substituir=true, apaga em cascata antes de criar. Retorna { criadasQ, criadasF, apagadas, erros }.

⑥ Camadas de segurança

🔐

Auth obrigatória

Ambas as APIs verificam o JWT do cookie e exigem role ADMIN. Qualquer outro role recebe 403. A rota é inacessível para alunos.

📥

Backup antes de tudo

O passo 1 é bloqueado até o admin baixar o arquivo JSON e marcar o checkbox de confirmação. Não é possível pular o backup.

☑️

Dupla confirmação destrutiva

O modo "Substituir tudo" exige um segundo checkbox na tela de confirmação. O botão de importar só fica ativo após ambos os checkboxes.

🔍

Validação linha por linha

O parser local identifica erros antes de enviar ao servidor: bloco inexistente, tópico errado, coluna "correta" inválida. Linhas com erro são ignoradas, as válidas são importadas.

🎯

Match por nome exato

A API não cria blocos ou tópicos novos. Só faz match com os que já existem (case-insensitive). Se não encontrar, registra erro na linha e pula — nunca falha silenciosamente.

📊

Relatório pós-importação

O passo 4 exibe exatamente quantos itens foram criados, quantos apagados (se substituiu) e a lista completa de linhas que falharam e o motivo.
